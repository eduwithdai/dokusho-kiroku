# よんだ本きろく — 読書記録カード支援アプリ

小学校の「読書記録カード」を、子どもがタブレットで記録できるようにするアプリです。
HTMLファイル1つで動きます。

## つかいかた

1. ホーム画面で自分の名前をえらぶ(はじめての人は「なまえを つくる」)
2. 「バーコードを よみとる」で、本の裏の 978 で始まるバーコードを読み取る
3. 本の名前と表紙が出るので、あっていれば「きろくする!」
4. 記録一覧の ★ をタップして、お気に入り度をつける

バーコードがない本は「じぶんで にゅうりょく」から手入力できます。

## 先生用の機能

ホーム画面右下の「先生用」ボタンを**押し続ける**と、円のゲージがたまって先生モードが開きます。

- 読書記録カード(A4)の出力 — 児童ごとに1枚。全員分または1人分を選べます
  - **iPadでは「PDFで保存」**を使ってください(共有画面から保存・印刷できます)
  - パソコンでは「カードを印刷」が使えます
- Excel出力(児童ごとのシート + 全員一覧)
- データのバックアップ・復元(JSON)
- 名前の削除

## データについて

**読書記録はサーバーに送信されません。** すべて各タブレットのブラウザ内(localStorage)に保存されます。
そのため、端末ごとにデータは独立しています。

- 端末を替えるときや学期末は、先生モードの「データを書き出す(JSON)」でバックアップしてください
- ホーム画面に追加して使うと、データが自動削除されにくくなります

## 書誌情報の取得元

ISBNから以下の順に検索し、書名・著者・表紙画像を取得しています。

- [openBD](https://openbd.jp/)
- [Google Books API](https://developers.google.com/books)
- [Open Library Covers API](https://openlibrary.org/dev/docs/api/covers)(表紙のみ)

## 動作環境

iPad / パソコンの新しめのブラウザ。カメラでのバーコード読み取りには HTTPS が必要です。
